## Passwords and MFA
Passwords must be at least 14 characters long. Use the company password manager. Multi-factor authentication (MFA) is mandatory for all accounts.

## Lost or stolen devices
Report a lost or stolen laptop or phone to security@acme.example within 1 hour.

## Data handling
Company data must not be stored on personal cloud storage or USB drives. USB storage is blocked on company laptops. All laptops have mandatory disk encryption.

## Networks
Use the company VPN when connected to public Wi-Fi.

## Phishing
Report suspicious emails with the Report Phishing button in the mail client.

## Software installation
Install software only from the IT self-service portal.
